# CUIT Evaluation Helper

- 成都信息工程大学教务系统自动评教辅助工具。
- 如果觉得有用，欢迎点个⭐Star～

## 功能特性

- 自动填写单选题（支持每道题独立配置选项）
- 自动填写文本框（默认填"无"）
- 一键批量完成所有教师评教
- 实时显示进度和状态

## 安装方法

1. 安装 Tampermonkey 浏览器扩展
2. 点击 [这里](https://greasyfork.org/zh-CN/scripts/581990) 安装
3. 进入教务系统评教页面即可使用

## 配置说明

### 题目选项配置（在脚本面板中设置）

| 配置方式 | 格式 | 示例 |
|---------|------|------|
| 范围配置 | `起始-结束:选项` | `1.1-1.11:0` |
| 精确配置 | `题号:选项` | `1.5:1` |
| 默认选项 | `数字` | `0` |

### 其他配置

- 文本框内容：默认"无"
- 延迟时间：默认 800ms

## 注意事项

- 本脚本仅供学习交流使用
- 请遵守学校相关规定，认真对待评教
